# Настройка проекта с нуля

Как развернуть reverse_bot на чистой машине после `git clone`. Подробности по
каждому шагу — в [README.md](README.md); здесь только порядок действий.

## 0. Что нужно заранее

- **Docker Desktop** (запущенный) — в нём собирается образ песочницы.
- **Python 3.10+** — хостовая часть (оркестратор, судья).
- **Windows** — команды ниже для PowerShell; на Linux/macOS замените `.ps1`/`.cmd`
  на прямые вызовы `docker`/`python`.

## 1. Хостовые зависимости

```powershell
pip install -r requirements.txt
```

Ставит `litellm` (доступ к моделям), `python-dotenv`, `paramiko` (SSH к Pi),
`PyYAML`. RE-инструменты (Ghidra, radare2, …) сюда НЕ входят — они живут в
контейнере.

## 2. Образ песочницы

```powershell
powershell .\build.ps1
```

Первая сборка 15–30 минут (Ghidra ~400 МБ). В конце прогонится самопроверка —
она печатает, что установилось. Критичен только JDK; часть инструментов помечена
необязательными. Для Pi OS 2023–2024: `.\build.ps1 -Suite bookworm`.

## 3. Локальный судья — необязательно (чтобы `truth/` не утекал)

Судья — единственный, кто видит `truth/` (исходник и секретные значения), и по
умолчанию шлёт это облачной модели. Если проект секретный, разверни судью
**локально** — данные не покидают машину. Один скрипт ставит Ollama, тянет модель
и проверяет её ответ:

```powershell
powershell -ExecutionPolicy Bypass -File .\install_qwen.ps1 -Model qwen3:30b
```

Ставит **Qwen3-30B** (~19 ГБ; MoE — 30 млрд параметров, но активны ~3 млрд на
токен, плюс режим рассуждения). Её описание — `models/judge_local_qwen3.txt`, на
которое `judge_model` в `RE_args.txt` настроен по умолчанию. Скрипт идемпотентен:
повторный запуск пропустит уже сделанное.

Почему именно она: судья по числовым константам должен не просто найти значение в
отчёте, а привязать его к нужной величине и отсеять случайные совпадения (одно
число бывает у разных целей). Это дискриминация, где слабые модели штампуют «да»;
режим рассуждения qwen3 её вытягивает, а MoE держит скорость. Плюс `judge.py`
делает детерминированный **пре-фильтр**: присутствие числа проверяет код (греп по
значениям), а модели остаётся только привязка — так галлюцинации о ненайденных
константах невозможны в принципе.

Требования: желательна NVIDIA-видеокарта, свободное место под модель и терпение —
один вызов судьи ~9–15 мин (оффлайн, после атаки не критично; тонко настраивается
через `RE_JUDGE_NUM_CTX` / `RE_JUDGE_TIMEOUT` / `RE_JUDGE_MAX_TOKENS`). Судья ходит
только через litellm и видит Ollama как `ollama_chat/…` без правок кода.

Альтернативы (нужно и поменять `judge_model` в `RE_args.txt` на соответствующее
описание):

```powershell
# qwen2.5:32b -- без рассуждения, медленнее, слабее на высокой вскрываемости
powershell -ExecutionPolicy Bypass -File .\install_qwen.ps1 -Model qwen2.5:32b
#   -> judge_model = models/judge_local32.txt
# qwen2.5:14b -- легче и быстрее, но заметно слабее на защитах (defense-инверсия)
powershell -ExecutionPolicy Bypass -File .\install_qwen.ps1 -Model qwen2.5:14b -MinFreeGB 12
#   -> judge_model = models/judge_local.txt
```

Пропустить шаг = облачный судья: верни `judge_model = models/judge_claude.txt`
(но тогда `truth/` уходит на чужой сервер).

## 4. Ключи и доступы — `.env`

```powershell
copy examples\.env.example .env
```

Открой `.env` и впиши **хотя бы один** ключ модели:

- `OPENROUTER_API_KEY` — один ключ на все модели (проще всего), либо
- прямые ключи провайдеров (`ANTHROPIC_API_KEY`, и т. д.).

Точные id моделей — на [openrouter.ai/models](https://openrouter.ai/models).
Это **API-доступ**, не подписка ChatGPT/Claude — оплачивается отдельно, по токенам.

### Подписка Claude — необязательно (маршрут `subscription`)

Claude можно гонять не по API-токенам-деньгам, а в счёт лимитов подписки Pro/Max
(маршрут `subscription`: `claude -p` в контейнере). Для этого нужен долгоживущий
токен:

1. Установи Claude Code CLI и выполни в терминале `claude setup-token` (нужен
   браузер один раз) — он напечатает годовой токен `sk-ant-oat01…`.
2. Впиши его в `.env`: `CLAUDE_CODE_OAUTH_TOKEN=sk-ant-oat01…` (в git не коммитить).

Тогда модель с `preferred_run_type = subscription` (см. шаг 7) пойдёт этим
маршрутом. Без токена агент откатится на `~/.claude/.credentials.json` (обычный
`claude auth login`, живёт ~8 ч и сам не обновляется — для регулярных прогонов
удобнее токен из `claude setup-token`). Маршрут только для **доверенного** бинаря:
контейнер Claude идёт с сетью и доступом к Pi.

Настоящая Raspberry Pi необязательна. Если есть — заполни блок `RE_PI_*`.
Как заполнять поля:

RE_PI_HOST
Выполнить "hostname -I" на Pi, взять полученное значение.

RE_PI_PORT
Порт SSH. Обычно 22, оставь как есть, если не менял.

RE_PI_USER
Выполнить whoami на Pi, взять полученное значение.

RE_PI_PASSWORD / RE_PI_KEY
Пароль для Pi / SSH-ключ для подключения к Pi.

RE_PI_WORKDIR
Рабочая папка на Pi. По-умолчанию "/tmp/re-<метка запуска>".

После заполнения проверь:

```powershell
python agent.py --check-pi
```

## 5. Данные — вручную, их нет в git

Два каталога намеренно исключены из репозитория (`samples/`, `truth/` в
`.gitignore`): там анализируемый бинарь, защищаемый исходник и эталонные ответы.
Создай и заполни их:

```
samples/                 # анализируемое (не в git)
├── <бинарь>             #   образец для атаки
└── <зависимости>        #   .so, данные, входные файлы, нужные ему для запуска

truth/                   # эталон — виден только судье (не в git)
├── src/…                #   защищаемый код с маркерами @re-target-*
└── Cargo.toml           #   (если Rust) — имя/версия бинаря
```

Разметь защищаемое в исходниках маркерами `@re-target-const` / `-algo` /
`-defense` (см. README → раздел про разметку), затем собери цели:

```powershell
python targets_gen.py --source truth --out truth/protected.yaml --cargo truth/Cargo.toml --check
```

`--check` показывает, что распозналось, без записи. Убедился — убери `--check`.

> **Граница доверия.** `truth/` виден только судье и никогда не попадает в
> песочницу к атакующим. Не клади исходник или `protected.yaml` внутрь `runs/` —
> оттуда он смонтировался бы в контейнер. `judge.py` это проверяет и откажет.

## 6. Проверка стенда (без трат на модели)

```powershell
python tests\smoke_sandbox.py
```

Гоняет контейнер вхолостую: PATH, монтирование, отсутствие сети, эмуляция ARM.
Ключей API не требует.

## 7. Запуск RE-сессии

Настройки делятся на два уровня:

- **`RE_args.txt`** — сама сессия: бинарь, зависимости, `attack_models`
  (атакующие — пути к `models/attack_*.txt` через запятую), `judge_model`
  (судья — один путь `models/judge_*.txt` или прямое litellm-имя), метка версии,
  пути эталона. Правь этот файл, не команду.
- **`models/<имя>.txt`** — описание одной модели (единый формат и для атакующих, и
  для судьи). Пары симметричны — `litellm_model`/`litellm_budget` (через
  OpenRouter, реальные $) и `subscription_model`/`subscription_budget` (через
  подписку, лимиты Pro), а `preferred_run_type` выбирает активный маршрут. У
  атакующего бюджет по активному маршруту обязателен (иначе явная ошибка).
  Примеры — `models/attack_claude.txt`, `models/judge_claude.txt`.
- **Судья** работает только через litellm (подписка пока не поддерживается: при
  `preferred_run_type = subscription` предупредит и уйдёт на litellm). Его
  `litellm_budget`, если задан, — предохранитель: judge.py оценивает стоимость
  единственного вызова заранее и отказывается, если она выше бюджета.

Затем:

```powershell
python run_RE.py
```

или

```powershell
run_RE.cmd
```

Прогонит всю цепочку: цели → атака ансамблем → оценка судьёй. Результат —
`runs/<прогон>/resilience.json` (балл стойкости и вердикт по каждой цели).

Отдельные шаги (`targets_gen.py`, `orchestrate.py`, `judge.py`) можно запускать и
вручную — см. README.

## Частые ошибки

- **`Docker недоступен`** — не запущен Docker Desktop.
- **`не задан ключ для <модель>`** — пустой `.env` или не тот ключ под id модели.
- **`access-токен подписки протух` / `нет токена подписки`** — маршрут
  `subscription`, но нет свежего доступа: задай `CLAUDE_CODE_OAUTH_TOKEN` или
  сделай `claude auth login` (см. шаг 4).
- **`не задан <…>_budget для маршрута <…>`** — в `models/<имя>.txt` нет бюджета
  по активному маршруту; впиши `litellm_budget` или `subscription_budget`.
- **`нет файла целей`** — не запускал шаг 5 (`targets_gen.py`).
- **`провайдер не знает модели`** — устаревший id; сверь с openrouter.ai/models.
- **`ОТКАЗ: … внутри runs/`** — эталон положен в `runs/`; перенеси в `truth/`.
